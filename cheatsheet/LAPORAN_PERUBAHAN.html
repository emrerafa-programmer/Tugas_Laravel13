Fitur Halaman Products — Laravel + Inertia.js + Vue

1. Tujuan

Membuat halaman untuk menampilkan tabel data products menggunakan stack teknologi Laravel (backend) dan Vue.js (frontend) dengan Inertia.js sebagai bridge di antara keduanya.

2. Files yang Diubah

No File Status Penjelasan
1 app/Http/Controllers/ProductController.php Diubah Dari class kosong menjadi memiliki method index()
2 routes/web.php Diubah Ditambah route GET /products
3 resources/js/pages/Products.vue Baru Halaman Vue untuk menampilkan tabel products
4 resources/js/components/AppSidebar.vue Diubah Ditambah menu "Products" di sidebar navigation

3. Detail Perubahan

3.1 ProductController.php

Lokasi: app/Http/Controllers/ProductController.php

Yang diubah: Class yang sebelumnya kosong ditambah method index().

Sebelum:

class ProductController extends Controller
{
    //
}

Sesudah:

use App\Models\Product;
use Inertia\Inertia;

class ProductController extends Controller
{
    public function index()
    {
        $products = Product::latest()->get();

        return Inertia::render('Products', [
            'products' => $products,
        ]);
    }
}

Penjelasan:

  • Product::latest()->get() — Mengambil semua data dari tabel products, diurutkan dari yang terbaru.
  • Inertia::render('Products', [...]) — Merender Vue component Products.vue dan mengirim data products sebagai props.

3.2 routes/web.php

Lokasi: routes/web.php

Yang diubah: Ditambah import ProductController dan route baru GET /products.

Sebelum:

Route::inertia('/', 'Welcome')->name('home');

Route::middleware(['auth', 'verified'])->group(function () {
    Route::inertia('dashboard', 'Dashboard')->name('dashboard');
});

Sesudah:

use App\Http\Controllers\ProductController;

Route::inertia('/', 'Welcome')->name('home');
Route::get('products', [ProductController::class, 'index'])->name('products');

Route::middleware(['auth', 'verified'])->group(function () {
    Route::inertia('dashboard', 'Dashboard')->name('dashboard');
});

Penjelasan:

  • Route /products ditempatkan di luar middleware auth, sehingga bisa diakses tanpa login.
  • Route mengarah ke ProductController method index.

3.3 resources/js/pages/Products.vue (File Baru)

Lokasi: resources/js/pages/Products.vue

Yang diubah: File baru dibuat sepenuhnya.

Kode lengkap:

<script setup lang="ts">
import { Head } from '@inertiajs/vue3';

interface Product {
    id: number;
    name: string;
    slug: string;
    description: string | null;
    price: number;
    discount_price: number | null;
    stock: number;
    sku: string | null;
    image: string | null;
    is_active: boolean;
    created_at: string;
}

defineProps<{
    products: Product[];
}>();

function formatPrice(price: number): string {
    return new Intl.NumberFormat('id-ID', {
        style: 'currency',
        currency: 'IDR',
        minimumFractionDigits: 0,
    }).format(price);
}
</script>

<template>
    <Head title="Products" />
    <div class="flex h-full flex-1 flex-col gap-4 overflow-x-auto rounded-xl p-4">
        <h1 class="text-2xl font-bold">Products</h1>
        <table class="w-full text-left text-sm">
            <thead>
                <tr>
                    <th>Name</th>
                    <th>Price</th>
                    <th>Discount</th>
                    <th>Stock</th>
                    <th>SKU</th>
                    <th>Status</th>
                </tr>
            </thead>
            <tbody>
                <tr v-for="product in products" :key="product.id">
                    <td>{{ product.name }}</td>
                    <td>{{ formatPrice(product.price) }}</td>
                    <td>{{ product.discount_price ? formatPrice(product.discount_price) : '-' }}</td>
                    <td>{{ product.stock }}</td>
                    <td>{{ product.sku || '-' }}</td>
                    <td>{{ product.is_active ? 'Active' : 'Inactive' }}</td>
                </tr>
            </tbody>
        </table>
    </div>
</template>

Penjelasan:

  • interface Product — Mendefinisikan tipe data products sesuai struktur database.
  • defineProps — Menerima data products dari backend Laravel.
  • formatPrice() — Fungsi untuk format mata uang Rupiah (IDR).
  • Tabel dengan 6 kolom: Name, Price, Discount, Stock, SKU, Status.
  • Badge warna: hijau (Active), merah (Inactive).

4. Konsep yang Digunakan

Konsep Penjelasan
Inertia.js Bridge antara Laravel backend dan Vue frontend. Memungkinkan SPA (Single Page Application) tanpa perlu membuat API terpisah.
Wayfinder Laravel Vite plugin untuk type-safe route generation di TypeScript, sehingga route name otomatis ter-generate sebagai function.
Controller Class PHP yang menangani request HTTP dan mengirim response (data + view).
Vue Component File .vue untuk frontend UI menggunakan Composition API (<script setup>).
Props Data yang dikirim dari parent (backend Laravel) ke child component (Vue) melalui Inertia.
Middleware Mekanisme Laravel untuk memfilter request, contoh: auth middleware hanya mengizinkan user yang sudah login.
Eloquent Model ORM Laravel untuk berinteraksi dengan database secara OO. Product::latest()->get() mengambil semua data.

5. Cara Menjalankan

  1. Pastikan MySQL sudah running (XAMPP Control Panel → Start MySQL)
  2. Buka terminal dan jalankan: 
    cd laravels
php artisan migrate
  3. (Opsional) Seed data products via tinker: 
    php artisan tinker
    Lalu paste: 
    App\Models\Product::create(['name' => 'Laptop', 'slug' => 'laptop', 'price' => 10000000, 'stock' => 50]);
App\Models\Product::create(['name' => 'Mouse', 'slug' => 'mouse', 'price' => 150000, 'stock' => 100]);
  4. Jalankan dev server: 
    php artisan serve
  5. Buka browser: http://localhost:8000/products

6. Catatan Penting

  1. Kenapa edit index.blade.php tidak berpengaruh?
    Project ini menggunakan Inertia.js + Vue, bukan Blade template biasa. Route / menampilkan resources/js/pages/Welcome.vue, bukan file Blade. Jadi halaman baru harus dibuat sebagai Vue component di resources/js/pages/.
  2. Kenapa awalnya harus login?
    Route /products awalnya ditempatkan di dalam middleware auth group. Solusi: memindahkan route ke luar middleware auth group.
  3. Error "Connection refused"?
    Artinya MySQL belum running. Pastikan MySQL di XAMPP sudah Start. Jika masih error, cek log di C:\xampp\mysql\data\mysql_error.log.
